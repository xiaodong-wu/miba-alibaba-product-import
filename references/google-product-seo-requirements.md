# Google 搜索引擎产品优化要求

> 适用范围：BNS Railings 独立站英文产品页  
> 版本日期：2026-08-27  
> 目标：让产品页更容易被 Google 抓取、理解和收录，同时提升搜索结果点击率、页面体验和询盘转化率。

## 1. 核心原则

1. 优先满足真实采购商的搜索与决策需求，再考虑关键词布局。
2. 每个产品页必须提供独立、准确、可验证的内容，不直接复制 Alibaba 或其他网站的文案。
3. 标题、正文、图片、参数和结构化数据必须描述同一个产品，不得夸大或填写页面上不可见的信息。
4. 关键词自然出现即可，禁止关键词堆砌、隐藏文字和批量生成低价值近似页面。
5. Google 不保证任何页面一定被收录或取得特定排名；发布后应通过 Search Console 持续监测并迭代。

## 2. 发布前关键词规划

每个产品页建立一组清晰的搜索意图：

| 类型    | 用途           | 示例                                               |
| ----- | ------------ | ------------------------------------------------ |
| 核心产品词 | 明确产品类别       | stainless steel rod railing                      |
| 长尾关键词 | 描述材质、结构和用途   | stainless steel rod railing for balcony          |
| 定制词   | 承接工程与 OEM 需求 | custom railing system、OEM railing                |
| 应用词   | 对应采购场景       | stair railing、deck railing、hotel balcony railing |
| 厂家词   | 表达供应能力       | manufacturer、factory、supplier                    |
| 品牌词   | 建立品牌识别       | BNS Railings                                     |

要求：

- 每页确定 1 个主要关键词、2–5 个相关长尾词。
- 同类产品不得只替换少量关键词批量复制页面。
- 同时考虑专业采购商与普通用户可能采用的不同搜索表达。
- 不设置 `meta keywords`；Google 搜索不使用该标记。

## 3. 产品名称与 SEO 元数据

### 3.1 产品标题（页面 H1）

建议结构：

`定制词 + 设计/材质 + 产品核心词 + 主要应用场景`

可按需要加入修饰词和厂家词，但必须保持自然、准确和易读。一个页面只设置一个主要 H1。

示例：

`Custom Stainless Steel Rod Railing for Stairs and Balconies`

禁止：

- 重复堆叠 `manufacturer / supplier / factory / wholesale`。
- 将所有规格、应用和同义词塞进同一个标题。
- 使用与页面实际产品不符的材料、认证、价格或应用信息。

### 3.2 SEO 标题（HTML `<title>`）

建议结构：

`修饰词 + 长尾关键词 + 厂家词 | 品牌词`

执行标准：

- 约 50–65 个英文字符，内部目标约 60 个字符；这是便于展示与管理的编辑标准，不是 Google 的强制长度。
- 使用自然的英文 Title Case，介词和冠词按正常英文规则处理。
- 每个页面标题唯一，准确概括该页面产品。
- 主要关键词尽量靠前，品牌词通常放在末尾。
- 不重复使用全大写、感叹号或促销词吸引点击。

示例：

`Durable Stainless Steel Rod Railing Manufacturer | BNS`

### 3.3 SEO 描述（Meta Description）

建议结构：

`品牌 + 产品/材质 + 核心优势 + 主要应用 + 定制能力`

执行标准：

- 140 个英文字符以内；这是本项目的内部编辑标准，不是 Google 的固定截断规则。
- 每个页面描述唯一，使用 1–2 句自然语言。
- 包含真实卖点，如 304/316 不锈钢、CAD 设计、OEM、易安装或项目定制。
- 不填写页面正文中没有说明的价格、交期、认证或质保。
- Google 可能根据用户查询从正文生成摘要，因此正文首屏同样必须清晰说明产品价值。

示例：

`BNS Railings supplies custom 304/316 stainless steel rod railing systems for stairs, balconies and decks, with CAD design and OEM support.`

## 4. URL、网站结构与收录

- URL 使用简短、可读、与产品对应的英文单词，例如：  
  `custom-stainless-steel-rod-railing`
- 使用小写字母和连字符，避免无意义编号、复杂参数和关键词堆砌。
- 每个产品只保留一个首选 URL，并设置自引用 `rel="canonical"`。
- 重复或旧 URL 应 301 重定向到首选页面；不能重定向时再使用 canonical。
- 产品页必须通过分类页、相关产品和面包屑链接被站内发现，不做孤立页面。
- 将有效产品 URL 写入 XML Sitemap，并在 Google Search Console 提交。
- 确保产品页、CSS、JavaScript 和关键图片不被 `robots.txt`、`noindex`、登录或权限限制阻挡。
- 多语言页面应使用独立 URL，并正确配置 `hreflang`，避免自动翻译内容相互覆盖。

## 5. 产品图片规范

### 5.1 文件标准

| 图片类型     | 尺寸              | 体积           | 格式   | 要求             |
| -------- | ---------------:| ------------:| ---- | -------------- |
| 产品缩略图/组图 | 800 × 800 px    | 单张不超过 100 KB | WebP | 产品清晰、主体完整、背景干净 |
| 详情页介绍图   | 按版面实际尺寸输出       | 单张约 100 KB   | WebP | 保证文字和细节可读      |
| 应用场景图    | 建议宽度不低于 1200 px | 在清晰前提下压缩     | WebP | 产品结构和安装逻辑合理    |

如果 100 KB 会造成明显失真，应优先保证采购商能看清产品细节，再做合理压缩。

### 5.2 SEO 与页面实现

- 文件名使用描述性英文，例如：  
  `custom-stainless-steel-rod-railing-white-background.webp`
- 每张重要图片添加简洁、准确、不同的 `alt` 文本，描述图片内容及其与页面的关系。
- 禁止在 `alt` 中堆砌关键词、厂家词或无关应用词。
- 图片放在相关标题和文字附近；应用图旁必须说明应用环境与产品优势。
- 首屏主图不得延迟加载；首屏以下图片可使用懒加载。
- 根据屏幕宽度提供响应式图片，避免手机端下载过大的桌面图片。
- 图片 URL 必须可以被 Google 直接访问并返回正常状态码。
- 图片内容必须与产品真实结构一致；AI 场景图不可产生错误立柱、悬空连接或不合理安装。

## 6. 产品详情页内容结构

推荐按以下顺序编排：

1. **首屏产品概览**：H1、产品组图、1 段价值说明、主要 CTA。
2. **产品介绍**：材质、结构、表面处理、设计特点和适用项目。
3. **参数表**：型号、材料、尺寸、厚度、表面处理、安装方式、可定制项等。
4. **产品优势**：用事实解释耐腐蚀、耐用、安装、维护和定制能力。
5. **应用场景**：楼梯、阳台、露台、酒店、商业建筑、住宅或户外项目。
6. **工程案例**：展示实际或合理模拟的安装效果，并提供场景说明。
7. **包装与交付**：包装方式、保护措施、可选贸易条款和交期说明。
8. **认证**：只展示真实、有效且与产品或工厂相关的认证。
9. **工厂/团队/办公场景**：说明生产、质检、设计和服务能力。
10. **公司优势与产品优势**：突出 BNS Railings 的真实能力，避免空泛口号。
11. **FAQ**：建议 6 个高价值问题，回答采购商在材质、尺寸、安装、定制、样品和交期方面的疑问。

内容要求：

- 使用自然、专业、无语法错误的英文。
- 长内容拆分为清晰的小节、段落、列表和表格。
- 每页文案必须独立编写并及时更新。
- 参数、认证、案例和评价必须可验证；禁止虚构。
- 不规定最低或最高字数，以完整回答采购问题为准。
- 页面主要信息应以可抓取文字呈现，不能只放在图片中。



## 7. 页面体验与技术性能

- 页面必须适配手机、平板和桌面端。
- 使用 HTTPS，避免混合内容、失效资源和重复跳转。
- 压缩图片、CSS 和 JavaScript，减少阻塞首屏的第三方脚本。
- 关键图片和文字加载后不得发生明显跳动。
- Core Web Vitals 目标（按真实用户数据第 75 百分位评估）：
  - LCP ≤ 2.5 秒
  - INP ≤ 200 毫秒
  - CLS ≤ 0.1
- 使用 PageSpeed Insights 和 Search Console Core Web Vitals 报告持续检测。
- 保证主要内容和功能在启用 JavaScript 后可被 Google 正常呈现；不要向 Googlebot 展示与用户不同的页面。

## 8. 发布验收清单

### 内容与关键词

- [ ] H1 准确、自然且唯一。
- [ ] 主要关键词与页面产品一致。
- [ ] 正文为独立内容，无关键词堆砌。
- [ ] 参数、认证、案例、评价和交付信息真实可验证。
- [ ] FAQ 含 6 个采购商真正关心的问题。

### SEO 元数据

- [ ] SEO 标题唯一，约 65 个英文字符。
- [ ] Meta Description 唯一，不超过 140 个英文字符。
- [ ] URL 简短可读
- [ ] 页面未被 robots.txt、`noindex` 或登录限制阻挡。

### 图片与视频

- [ ] 组图为 800 × 800 px、WebP，目标不超过 100 KB。
- [ ] 详情图在清晰前提下压缩至约 100 KB。
- [ ] 文件名和 `alt` 文本准确描述内容。
- [ ] 首屏主图未懒加载，其他图片按需懒加载。

## 9. 明确不采用的做法

- 不使用 `meta keywords` 作为优化手段。
- 不堆砌同义关键词、地区词、厂家词或品牌词。
- 不以正文长度作为排名目标。
- 不创建大量内容高度相似的产品页抢占关键词。
- 不复制 Alibaba、竞争对手或旧产品页的完整文案。
- 不购买或批量制造低质量外链。
- 不伪造价格、库存、评分、评论、认证或工程案例。
- 不承诺“保证收录”“保证首页”或固定时间取得排名。
